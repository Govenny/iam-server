# 平台管理与运营中枢 (Platform Admin Console) 规范文档

## 1. 概述与设计定位

本模块为昆山督导系统 / 统一数智底座的**平台超级管理员 (`PLATFORM_ADMIN`)** 与 **平台运营专家 (`PLATFORM_OPERATOR`)** 专属管理中枢。

当企业主账号或子账号登录时，界面仅呈现所属租户的“企业成员与权限”和“工作空间管理”；当平台超管/运营登录时，页面顶部自动激活**平台运营中枢 / 租户工作台**双视图切换控制器，并默认切入包含 5 大管理中枢的全局运营视图。

---

## 2. 核心架构与 5 大中枢 Tab

```
┌─────────────────────────────────────────────────────────────┐
│                    平台运营中枢 (Admin Console)              │
├──────────────┬──────────────┬──────────────┬────────┬───────┤
│  1.数据看板   │ 2.租户企业治理│ 3.全域用户中心│ 4.跳传审计│ 5.归档监控│
└──────────────┴──────────────┴──────────────┴────────┴───────┘
```

### 2.1 Tab 1: 数据总览看板 (`/api/v1/admin/dashboard/stats`)
- **核心业务指标**：
  - 入驻企业与组织数（包含企业租户数、待审核实名认证企业数）；
  - 全域注册用户数（主账号数、子账号数、正常活跃数）；
  - 纳管项目工作空间数；
  - 今日跨底座免密跳传原子人次。
- **底座热度分布**：
  - 模型工程平台 (`MODEL_ENGINE`)
  - 算力调度平台 (`COMPUTE`)
  - Agent 工程沙箱 (`AGENT`)
  - 信通院数据空间 (`CAICT_DATA_ENG`)
- **底层组件健康雷达**：
  - MySQL 数据库连接池健康状态；
  - Redis 票据原子缓存存活状态；
  - Casdoor IDP 认证底座同步状态；
  - 统一网关 HMAC-SHA256 签名验签服务状态。

---

### 2.2 Tab 2: 租户与企业管理 (`/api/v1/admin/tenants`)
- **能力**：
  - 支持按企业名称、租户ID、租户类型（企业/个人）、实名状态组合检索；
  - **实名认证审核**：未认证 (0) / 审核中 (1) / 审核通过 (2) / 驳回 (3)；
  - **免计费白名单穿透**：针对中试基地官方演示与特定合作企业，开启 `is_exempt_billing=1` 后统一网关免扣减算力额度；
  - **企业冻结/解冻**：一键冻结企业，禁止该企业下属所有主子账号向底座发起跳转换票。

---

### 2.3 Tab 3: 全域用户中心 (`/api/v1/admin/users`)
- **能力**：
  - 跨租户跨组织搜索全局用户（支持用户名、姓名、全局 UID、状态、账号类型过滤）；
  - **账号启停状态治理**：正常启用 (1) / 冻结封禁 (2)；
  - **全局角色调整**：研发专家 / 企业管理员 / 财务审计 / 只读访客 / 平台运营 / 官方演示 / 平台超管；
  - **Casdoor 密码重置维护**：超管直接填入新密码并原子同步至 Casdoor IDP。

---

### 2.4 Tab 4: 底座免密跳传与网关审计 (`/api/v1/admin/audit/tickets`)
- **能力**：
  - 实时抓取 Redis 审计队列（`audit:jump_tickets`）最新 200 条流水；
  - 审计事件状态：
    - `ISSUED`：票据已签发（60 秒有效，待消费）；
    - `VERIFIED`：底座平台完成原子核销，状态流转为已消费；
    - `REPLAY_BLOCKED`：拦截针对已核销票据的二次重放攻击；
    - `PLATFORM_MISMATCH`：拦截伪造或错配的目标平台跳传请求；
    - `EXPIRED`：票据超时自然失效。

---

### 2.5 Tab 5: 中台离线日文件归档监控 (`/api/v1/admin/sync/files`)
- **规范标准**：符合《国家工业中试基地与数智中台 统一接口规范》第 3 章离线对账规范。
- **文件清单**：
  - 3.2.1 用户信息-日文件：`USER_INFO_{YYYYMMDD}.000`
  - 3.2.2 用户属性信息-日文件：`USER_ATTR_{YYYYMMDD}.000`
- **操作能力**：超管可随时点击“立即执行今日文件生成与归档”（`POST /api/v1/sync/export-data-middle-platform`），采用 `.tmp` 原子重命名写入方式完成离线归档并实时回显数据行数。

## 3. 页面访问与联调方式

| 访问场景 | URL 参数 | 呈现视图 |
| :--- | :--- | :--- |
| **超管运营快速调试** | `http://localhost:8001/ui?admin=1` | 自动签发 `PLATFORM_ADMIN` 权限，默认呈现**平台运营中枢** 5 大 Tab |
| **超管指定 Token** | `http://localhost:8001/ui?portal_token=token_p_admin_ops` | 自动识别超管权限，呈现平台运营中枢并支持切换到租户视图 |
| **企业普通主账号** | `http://localhost:8001/ui` 或 `?portal_token=token_p_9001_zhangsan` | 呈现**租户工作台**（成员与权限、工作空间管理），隐藏管理中枢 |
